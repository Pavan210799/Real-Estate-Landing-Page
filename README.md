# Real Estate Landing Page

Pixel-perfect React + Vite implementation of the **Real Estate Landing Page** from the UI8 Landing Page Web UI Kit (Figma).

## Stack

- React 19
- Vite 6
- CSS (design tokens from Plumb / Figma)

## Design tokens

| Token | Value |
|-------|-------|
| Navy | `#0d2038` |
| Gold | `#d0b580` |
| Light bg | `#f9fbff` |
| Dark text | `#0d1117` |
| Display font | Cormorant Garamond (Bon Vivant substitute) |
| Body font | Jost (Brandon Grotesque substitute) |
